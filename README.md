# mono-gs-slam-uav

Монокулярный SLAM на основе 3D Gaussian Splatting для БПЛА. Сделан в рамках НИР
(7 семестр, Самарский университет, кафедра технической кибернетики).

Автор: Конкин А. А., группа 6302-010302D  
Научный руководитель: Минаев Е. Ю.

## Что умеет

По видео с одной камеры система оценивает траекторию камеры и параллельно строит
карту сцены из 3D-гауссиан.

- инициализация по двум кадрам (ORB, существенная матрица, триангуляция);
- глубина ключевых кадров считается сетью Depth Anything V2 Small, масштаб
  подгоняется по триангулированным точкам;
- маппинг по ключевым кадрам, позы кадров в окне уточняются вместе с картой;
- прямой трекер (Гаусс–Ньютон) с аффинной моделью экспозиции и ограничением на неё;
- два режима: синхронный (маппинг после трекинга в одном потоке) и асинхронный
  (маппинг в отдельном потоке, кадры идут в темпе камеры).

Проверял на EuRoC MAV: V1_01_easy, V1_02_medium, MH_01_easy, MH_05_difficult.

## Что нужно

- NVIDIA GPU (у меня GTX 1060 6 ГБ), Windows 10 или Linux;
- Python 3.10;
- PyTorch 2.4.1 с CUDA 12.4;
- gsplat 1.4.0, собранный из исходников (см. ниже);
- остальное в `requirements.txt`.

## Установка

```
conda create -n gsslam python=3.10 -y
conda activate gsslam
pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
```

gsplat с pip на GTX 1060 не работает (у карты compute capability 6.1, готовые
сборки под неё не собраны). Поэтому собираю из исходников с небольшим патчем:

```
git clone --recursive --branch v1.4.0 https://github.com/nerfstudio-project/gsplat ../gsplat_src
python scripts/patch_gsplat_gtx10.py ../gsplat_src
pip install --no-build-isolation ../gsplat_src
```

На более новых картах патч, скорее всего, не нужен, хватит `pip install gsplat==1.4.0`.
Проверить, что всё встало:

```
python scripts/check_gpu.py
python tests/test_trajectory.py
```

## Данные

EuRoC MAV лежит в ETH Research Collection большими zip-архивами. Скрипт
`download_euroc.py` скачивает из архива только нужную последовательность:

```
python scripts/download_euroc.py --list machine_hall
python scripts/download_euroc.py --get vicon_room1 vicon_room1/V1_01_easy/V1_01_easy.zip --out data/euroc
```

После распаковки должно получиться `data/euroc/V1_01_easy/mav0/...`.
Первый запуск сам скачает веса Depth Anything V2 с Hugging Face.

## Запуск

Фрагмент 400 кадров (20 с) в итоговой конфигурации:

```
python scripts/run_slam.py data/euroc/V1_01_easy --tracker direct --start 900 --n-frames 400 --tag v1_900
```

Асинхронный режим – тот же запуск с `--async`. Весь полёт – без `--start` и `--n-frames`.
Все параметры: `python scripts/run_slam.py --help`.

Результаты пишутся в `outputs/slam/<последовательность>_<tag>/`:

- `metrics.json` – ATE, RPE, PSNR, время по модулям;
- `est_tum.txt`, `gt_tum.txt` – траектории в формате TUM (можно смотреть через evo);
- `track_log.json` – журнал трекинга по кадрам;
- `trajectory.png` – график траектории и ошибки.

Серии экспериментов из отчёта: `scripts/run_main_experiments.sh` (основная таблица) и
`scripts/run_reject_ablation.sh` (абляция отбраковки поз). Сравнение двух серий:
`scripts/paired_comparison.py`.

## Результаты

Синхронный режим, 22 фрагмента по 20 с, 3 зерна, GTX 1060:

- медианная ATE на фрагментах 19–75 см (2,3–4,5 % длины пути), лучшие фрагменты 3,6–6,7 см;
- на полных полётах ошибка 1,7–6,3 м, в основном из-за дрейфа масштаба;
- трекинг около 22 мс на кадр при бюджете 50 мс (камера 20 Гц);
- асинхронный режим успевает за камерой, но в 2,1 раза менее точен.

До ORB-SLAM3 и DSO по точности далеко: нет замыкания циклов и совместной
оптимизации поз и геометрии. На Jetson AGX Orin не запускал, так что про работу
в реальном времени на борту ничего утверждать не могу.

## Структура

```
gsslam/
  data/      загрузка EuRoC, глубина из лазерного скана
  depth/     Depth Anything V2 и выравнивание глубины
  geometry/  ORB и триангуляция
  map/       карта гауссиан, функция потерь, MLP для смаза (не вошёл в итог)
  track/     трекеры: прямой и через дифференцируемый рендеринг
  slam/      инициализация, маппинг, синхронная и асинхронная система
  eval/      ATE, RPE
  utils/     таймеры
scripts/     запуск, серии экспериментов, сводки, проверки
tests/       тест метрик траектории
```

## Ограничения

- нет замыкания циклов и релокализации: если трекинг сорвался, он не восстанавливается;
- масштаб дрейфует на длинных полётах;
- тонкие объекты (1–2 пикселя) карта размывает;
- динамические объекты не проверялись, в EuRoC их нет.
